# Global working agreements

- Lead with the outcome and keep routine explanations concise.
- Inspect existing code and conventions before editing.
- Preserve unrelated user changes.
- Run the smallest relevant tests, formatting checks, and type checks after changes.
- Report what was verified and anything that could not be run.
- Ask before adding production dependencies or performing external writes.
- Avoid destructive Git operations unless explicitly requested.
- Keep language-, framework-, and repository-specific commands in the repository's own `AGENTS.md`.

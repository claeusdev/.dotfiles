# Emacs Tutorials

The Emacs tutorial content has been split into two focused guides:

- [Emacs Development Workflow](emacs-dev-workflow.md)
- [Emacs Org Workflow](emacs-org-workflow.md)

If you are learning the setup from scratch, start with the development workflow first and then read the Org workflow.

For a new machine, read [Emacs setup overview](emacs.md) first and run the built-in health check on `C-c e h`.

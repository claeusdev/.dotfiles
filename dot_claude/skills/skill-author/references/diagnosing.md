# Diagnosing a skill that is not working

**Never fires.** The description is abstract, or its vocabulary does not match what the user
types, or a neighbour's description swallows the trigger first. Fix the description; the body
is almost never the cause.

**Fires constantly.** The trigger clause is too broad or the negative clause is missing.
Tighten with the concrete situation, not with "only use this when appropriate."

**Fires but is ignored.** The body is advice rather than instruction, or it is long enough
that the operative sentence is buried. Cut, then put the operative sentence first.

**Fires and does the wrong thing.** Usually two skills matched and the other one won. Add a
mutual "do not use for" naming the other by name.
